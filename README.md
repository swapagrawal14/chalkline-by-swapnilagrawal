# Chalkline

Whiteboard animation studio in the browser. Drop photos, stamp icons, type copy — a hand draws it on the board. Export WebM or a still PNG. No account. Boards stay on this device.

## Run it

```bash
npm install
npm run dev
```

Open the URL the command prints, then **Start a board**.

## Studio

- Motion packs under the canvas (sketch artist, chalk talk, rain, typewriter, bounce…)
- 23 drawing orders, stroke styles, hands, easing, entrances
- Scenes, captions, Ken Burns, chalkboard / blueprint looks
- Present mode, grid/snap, speech bubbles, JSON import/export
- Space to play, `F` present, `G` grid, `?` shortcuts

Everything is client-side (IndexedDB). Export records the canvas in this tab.
